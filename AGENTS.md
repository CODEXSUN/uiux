# Repository agent instructions

Read the shared [governance](../../assist/GOVERNANCE.md) and [agent guide](../../assist/AGENT.md) before working in this repository. Follow repository-specific instructions as well. Preserve existing work and report verification and limitations.

Assist may be absent in a standalone checkout. If Assist is unavailable, state that limitation and do not assume its rules or server connections are present.
